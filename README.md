# Task-Management-System
Web-based task management system using Java, Servlets, JDBC, MySQL, HTML, CSS, JavaScript
It allows role-based task management for Admin, Faculty, and Students, including secure authentication, task submission, and review.

## Features

### User Roles & Authentication
- Admin, Faculty, Student roles
- Secure login/logout with session management
- Role-based access control

### Student Features
- Dashboard with assigned tasks, upcoming deadlines, and submission status
- View and submit tasks with file upload (PDF/ZIP/Image/Code)
- Submission history tracking and comments

### Faculty Features
- Create, edit, delete, and assign tasks
- Review student submissions, provide marks, and update status
- Dashboard with pending reviews and completed submissions

### Admin Features
- User management (create, edit, activate/deactivate users)
- Batch/course management
- System overview of users, tasks, and submissions

### Other Features
- File upload system with validation
- Search and filter tasks, students, and submissions

## Tech Stack
- **Backend:** Java, Servlets, JDBC  
- **Frontend:** HTML, CSS (Tailwind), JavaScript  
- **Database:** MySQL  
- **Server:** Apache Tomcat

## How to Run
1. Install JDK (17 or higher)  
2. Install Apache Tomcat (10+)  
3. Install MySQL and import database schema  
4. Configure `DBConnection.java` with database credentials  
5. Deploy the project on Tomcat server
